## Limitations and decisions

The all-response linear slope remains the charter-requested primary
description. The early/late comparison concerns 20 extrema selected from 704
linear trends, so directional agreement is a robustness diagnostic rather than
an independent discovery procedure. Its direct percentage-point difference is
not on the same scale as the annualized linear slope.

The common calendar split does not impose a trajectory within either half, but
it can hide shorter reversals. It does not correct changing sample composition,
nonrepresentative recruitment, population weights, respondent turnover,
selective retention, time-varying confounding, or selection of extremes.
Nominal clustered intervals are therefore not promoted as population-change
claims, particularly because neither primary multiplicity screen finds a
discovery.

Only six monitoring rows now exist, so five healthy daily intervals do not
establish service reliability. No production system, public Ipseity Daily
page, website report, deployment configuration, `.env`, system runtime,
external account, PI-owned charter, earlier iteration record, or PI blockquote
was modified. Publication remains Unpublished.
