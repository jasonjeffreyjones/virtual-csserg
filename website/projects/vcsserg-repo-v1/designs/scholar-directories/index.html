Decision archive / Scholar directory

Three ways
to meet the group.

Each alternative links the same authoritative profiles and avoids adding biography. They differ in whether people, working relationships, or voice leads.

Decision: Dr. Jones selected A for Version 1. Its equal-card portrait roster is now implemented in the production Scholar directory; these dated prototypes remain comparison artifacts.

A / Portrait roster

People first

Three parallel cards give every Scholar equal visual weight, a short charter-grounded introduction, and a direct profile link.

Best for: quick orientation.
Tradeoff: current project relationships stay secondary.

Open alternative A →

B / Work map

Collaboration first

A compact roster sits beside a matrix connecting Scholars to their documented current projects.

Best for: understanding who is doing what.
Tradeoff: the matrix requires frequent maintenance.

Open alternative B →

C / Field guide

Voice first

Long horizontal entries foreground each full supplied biography before showing the current assignment.

Best for: memorable personalities.
Tradeoff: long biographies make scanning slower.
